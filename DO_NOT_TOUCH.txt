## Protected data
- Existing customer data in pelanggan
- Legacy product data in produk
- Transaction history in transaksi
- Any uploaded product images in storage/app/public/products/

## Prohibited actions in Phase 0
- php artisan migrate
- php artisan migrate:fresh
- php artisan db:seed
- DROP/TRUNCATE/ALTER TABLE
- DELETE from protected tables
- Modifying .env to point to another database
- Changing table prefixes or connections
